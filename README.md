# news-image-20261120

[![make.fun · news-image-20261120](https://make.fun/badge/news-image-20261120.svg)](https://make.fun/bounty/news-image-20261120)

One image that sums up the world news of **Friday, 20 November 2026**.

Layout: a front page dated 20 November 2026 with a lead on the Shenzhen
trilateral ("nuclear war must never be fought"), the ICJ ruling that Myanmar
committed genocide against the Rohingya, Houthi strikes on Riyadh's tallest
tower, Cyclone Akvan's landfall in India, Europe's €45bn offer to Kyiv,
Anthropic's market debut, and briefs on the Comanchero sanctions, Australia's
settler sanctions and Somalia's expulsion of the UAE envoy.

## Run

```bash
python3 main.py                       # writes /output/entry.png
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`poster/poster.html` is the artwork source; `poster/render.py` renders it at
2x and downscales to 1024×1024.
